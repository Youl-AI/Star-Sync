## 0. 컨셉

**성소(The Sanctum).** 밤의 의식. 달무리, 부드러운 발광, 세리프의 속삭이는 문장.
타로 카드를 뒤집는 순간의 설렘을 웹으로 — 단, 내용물은 무작위가 아니라 실제 하늘이다.

사이트는 두 세계로 나뉜다:

| 세계 | 페이지 | 테마 |
| --- | --- | --- |
| **밤 (의식)** | 메인, /natal, /today, /synastry, /yearly, /sign, /retrograde | 다크 고정 |
| **새벽 (기록)** | /blog, /about, /privacy, 이용약관 등 문서 전부 | 라이트 고정 |

페이지 단위 테마 고정(페이지 안에서 섹션 반전 금지). 두 세계는 금 액센트와 마루부리가 잇는다.
경계 연출: 새벽 글 하단 CTA("이 이야기를 내 하늘에서 보기") → 노을처럼 어두워지며 밤으로 입장.

다이얼: `DESIGN_VARIANCE 8 / MOTION_INTENSITY 8 / VISUAL_DENSITY 3`. 새벽 페이지는 MOTION 3.

## 4. 카드 물성 — "아치의 문" (사이트 전체 통일)

별자리 카드, 오늘의 카드, 공유 이미지 전부 이 형태. 다른 카드 모양 금지.

- **형태**: 상단 아치(반원) + 하단 살짝 둥근 직각. 상단 반경 = 카드 폭의 절반
  (예: 폭 212px → `border-radius: 106px 106px 10px 10px`).
- **이중 베젤**: 바깥 얇은 금테(`rgba(201,162,39,.32)`, 패딩 7px) + 안쪽 본체(금테 `.6`).
- **쐐기별**: 아치 정점에 작은 금별(✦).
- **내용 구성**: 상단 아치 안 성좌(금선+미색 별, 최밝성엔 이중 링) → 이름(마루부리) →
  영문·날짜(자간 넓은 소문자) → **선-다이아-선 구분선** → 이탤릭 한 줄 별칭.
- **선-다이아-선**은 사이트 공통 장식 언어 (카드 구분선, 새벽 문서 제목 아래, 로고 매듭 아님).
- 둥근 네모(`rounded-xl` 류)는 UI 버튼·입력창·필에만 허용. "운명이 담기는 그릇"은 전부 아치.

## 5. 네비게이션 — "얇은 베일" (1-A)

- 전폭 투명 바. 좌측 로고(A2 워드마크), 우측 링크(오늘의 하늘 · 천궁도 · 궁합 · 칼럼) +
  금테 필 CTA 1개("내 밤하늘").
- 스크롤 시: 반투명 먹빛(`rgba(19,22,41,.75)`) + blur 베일 + 하단 금 헤어라인.
  blur는 sticky 요소라 성능 허용.
- 새벽 페이지에선 같은 구조의 새벽 배색 버전.
- 모바일: 로고 + 햄버거. 햄버거는 X로 모프. 메뉴는 별하늘 배경 전체화면 오버레이,
  링크는 스태거 등장.
- 높이 64~72px. 데스크톱 한 줄 필수.

## 6. 페이지별 확정 디자인

### 6.1 메인 히어로 — 3장면 시퀀스 (페이지 이동 없음, WebGL 캔버스 하나)

1. **장면 ① 도착 (비대칭 창)**: 거대한 달이 우상단 모서리에 걸침(이중 링 달무리).
   좌하단에 헤드라인 "당신이 태어난 밤, 하늘은 기억하고 있어요"(이탤릭 강조는 금색) +
   서브 한 줄 + 금 필 CTA("나의 밤하늘 보기") + 보조 링크("오늘의 하늘").
   마우스 시차로 달·별 미세 이동.
2. **전환 (1.2초)**: CTA 클릭 → 달이 화면 중앙 상단으로 흐르고 헤드라인은 별빛 파티클로 흩어짐.
3. **장면 ② 의식의 시작 (중앙 제단)**: 중앙 달무리 + "어느 밤에 태어나셨나요?"
4. **장면 ③ 입력 의식**: 달무리 아래 언더라인 입력이 한 단계씩 — 생년월일 → 시간("모름" 옵션
   필수) → 도시(한글 자동완성) → 관심사(선택지 탭). 입력마다 배경 별들이 그 날짜 하늘로 조금씩 이동.
   완료 순간 별들이 모여 천궁도로 조립(시그니처 연출) → 결과.

메인 히어로 아래 섹션: ② 오늘의 하늘 티저(실데이터 카드 1장 + /today 진입) ③ 세 개의 문
(천궁도/궁합/연간 비대칭 벤토 3셀, 각 셀 실제 비주얼) ④ 결과 미리보기(실물 캡처 1장) ⑤ 푸터.
마퀴 0개, 스크롤 유도 문구 금지, 커스텀 커서 금지.

### 6.2 결과 화면 — "부적 인장"

- 상단: 천궁도 SVG가 선 드로잉으로 자기를 그림.
- 시적 제목 (예: "불꽃을 품고 태어난 사람") → 시적 총운 문단.
- **부적 칩**: 금테 원형 필 `♂ 화성 ☌ 태양 · 2.1°` — 문단 사이·문단 아래 배치, 탭하면
  "이 각도가 왜 중요한가" 풀이 확장. 데이터는 장신구, 서사가 주인공.
- 점수: 별처럼 떠 있는 숫자 3개(재물·관계·직업, 카운트업 애니메이션). 게이지 바 금지.
- 하단: [AI로 더 깊이 보기] 옵트인 버튼(자유 질문 입력은 이 안에서) + 카카오 공유 + 이미지 저장.
- 공유 이미지 = 아치 카드 형태로 렌더.

### 6.3 /today — "오늘의 카드"

- 첫 화면: 아치 카드 1장. 앞면 = 오늘 날짜·달 위상·달의 별자리·시적 한 줄 (12별자리 공통,
  cron 생성분). 터치하면 뒤집힘 → 뒷면 = 개인 트랜짓 (오늘 하늘 × 내 출생 차트, 아톰 DB 조립,
  LLM 0회): 오늘의 한 줄 + 부적 칩 2~3개(강도순) + 좋은 흐름/조심할 흐름.
- 생일은 첫 1회 입력 후 localStorage 저장 → 재방문 시 즉시 내 카드.
- 스크롤 아래: "밤의 대시보드" 확장 영역 (달 스트립 + 오늘의 각도 리스트 + 12별자리 필) —
  **10월 폴리시 단계에서 구현**, 9월엔 카드만.
- 공유: "오늘의 내 카드" 이미지 저장.

### 6.4 /sign — "천구의(Astrolabe) 진" + FLIP 모프

- **진 (목록 /sign)**: 이중 금선 링 + 사분 눈금 + 도수 점. 성좌 12개가 별무리 그대로
  링 위에 떠 있음 (박스·글리프·상시 이름표 없음, 감광 55%).
  진 전체가 분당 1° 자전. 중앙 문구 "열두 개의 방".
- **호버**: 그 성좌만 별 점등 + 금선 드로잉 + 이름·날짜 떠오름 + 해당 구간 호(arc)가
  금빛으로 달아오름 + 중앙 문구가 그 별자리로 바뀜 + 자전 일시정지. 스프링 물리.
- **클릭**: GSAP FLIP — 나머지 11개 감광·후퇴, 선택 성좌가 중앙으로 날아와 커지고
  아치 테두리가 stroke 드로잉으로 감싸며 카드로 응결(0.8초). URL은 pushState로
  `/sign/<별자리>` 갱신. 뒤로가기는 역모프.
- **구현 제약(필수)**: 성좌 12개는 각각 독립 DOM/SVG 요소로 원형 배치 — 단일 SVG 한 덩어리로
  그리면 FLIP 불가.
- **모바일**: 드래그로 다이얼 회전, 12시 방향 성좌 자동 점등, 탭 입장.
- **SEO**: `/sign/<별자리>`는 정적 페이지로도 존재(직접 착지 시 모프 없이 완성 HTML).
  본문: 성좌 카드 + 기본 해석(2,000자+) + 이번 달 트랜짓 + 2027 요약 + /natal CTA.

### 6.5 /synastry — "금실"

두 사람의 별무리가 좌우에 뜨고 금실이 곡선으로 이어짐(선 드로잉) → 공명 점수 카운트업 →
한 줄 요약 → 부적 칩(시너스트리 어스펙트). 공유 카드 = 두 별무리 + 점수.

### 6.6 /yearly — "강물 타임라인"

1년이 흐르는 곡선 하나. 스크롤하면 선이 그려지며 금빛 노드(실제 트랜짓 날짜)가 떠오름.
노드 탭 = 그 시기 풀이. 상반기/하반기 요약 필. 중요 날짜 캘린더는 이 강의 확대판.

### 6.7 /retrograde — "역행 고리"

수성의 실제 역행 고리 궤적 시각화 + 현재 상태("지금은 순행 중") + D-day.
역행 중엔 D-day가 종료일 기준으로 반전. 아래로 향후 2년 일정 + SEO 텍스트.

### 6.8 새벽 문서 (블로그 · 정책)

- 구조 = "밤의 서재"(2-B): 장(章) 번호 + 중앙 제목 + 선-다이아-선 + 첫 글자 금색 드롭캡.
- 상단 금색 읽기 진행선. 본문 65ch 단일 칼럼, 행간 넉넉히.
- 본문 중 관련 개념은 새벽 배색 부적 칩으로 인라인 (예: `☿ 수성 역행 · 9.17 - 10.9`).
- 글 하단 CTA "이 이야기를 내 하늘에서 보기" → 노을 전환으로 밤 입장.
- 정책 문서(개인정보처리방침·이용약관·쿠팡 고지)는 같은 템플릿에서 장식(드롭캡·장 번호) 제거판.

### 6.9 마이크로 순간

- **404**: 밤하늘에 홀로 깜빡이는 별 하나 + "길 잃은 별이네요" + 홈 링크.
- **AI 대기(옵트인 스트리밍)**: 별똥별이 선을 그리는 드로잉 루프.
- **에러**: 미색 텍스트로 정중하게. raw 에러 노출 금지.
- **빈 상태**: 별 하나 + 안내 한 줄.
- 버튼 `:active`는 `scale-[0.98]`. 스켈레톤은 최종 레이아웃 형태로.

## 7. 모션 규칙

- Lenis 전역 스무스 스크롤. GSAP ScrollTrigger 핀 섹션은 메인 1곳 + 결과 1곳만.
- GSAP(장면 전환·FLIP·스크롤텔링)과 Motion(버튼·카드 마이크로)은 같은 컴포넌트 트리에 혼용 금지.
- 스프링 물리 `stiffness 100 / damping 20`. linear·ease-in-out 금지.
- 모든 모션은 한 문장으로 이유를 댈 수 있어야 함 (위계/서사/피드백/상태 전환).
- `prefers-reduced-motion`: WebGL 정지 화면, 모프는 즉시 전환, 시차·자전 정지. 전면 대응.
- `window.addEventListener('scroll')` 금지. transform/opacity만 애니메이션.

## 8. 성능 가드레일

- LCP < 2.5s: 첫 페인트는 CSS 그라디언트 하늘 → WebGL 캔버스 페이드인(지연 로드).
- WebGL 폴백 3단계: 데스크톱 풀 씬 / 모바일 파티클 축소 + DPR 1.5 캡 / 미지원·reduced-motion은
  정적 별하늘.
- Three.js는 메인·결과에만 dynamic import. /sign·/retrograde·새벽 페이지에 번들 금지.
- 아톰 DB JSON은 라우트별 분할 로드.
- CLS < 0.1, 모바일 `<768px` 전 레이아웃 1열 붕괴 명시, `min-h-[100dvh]`(h-screen 금지).
- Lighthouse 90+ 확인 후 완료 선언.
